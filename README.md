# Tibebe Portfolio Scaffold

Initial Vue 3 + Vite + Pinia scaffold for a portfolio site inspired by the interaction language of the approved reference.

## Included

- Vue router setup
- Pinia state store
- content arrays for projects and assets
- setup preview screen
- asset inventory screen
- initial visual language placeholder styles

## Current goal

Review the structure, asset model, and content/state approach before building the full interactive portfolio.

## Next build phase

- add custom cursor system
- add hover/click annotation layers
- replace placeholders with approved assets
- split the page into final editorial portfolio sections

## Install and run

```bash
pnpm install
pnpm dev
```

# Colors

Goal:

- Move repeated project colors into named Tailwind tokens.

Suggested tokens:

- `bg`
- `paper`
- `ink`
- `accent`
- `reference-dark`
- `reference-light`

Expected usage:

- `bg-paper`
- `text-ink`
- `border-ink`
- `bg-reference-dark`

Why:

- Reduces repeated hex and rgba values.
- Makes theme changes much easier.

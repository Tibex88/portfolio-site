# Fonts

Goal:

- Centralize font families in Tailwind config.

Suggested font families:

- `display`
- `ui`
- `script`
- `callout`
- `body`

Expected usage:

- `font-display`
- `font-ui`
- `font-script`
- `font-callout`
- `font-body`

Why:

- Reduces custom font declarations in classes.
- Keeps the reference-inspired font system easier to swap later.
